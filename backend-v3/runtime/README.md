# 검수 완료 런타임 자산

이 폴더는 API 비밀키나 응답 샘플이 아니라, 공식 공개문서로 검수한 정적
규칙과 지역 키만 담는다.

## 포함 범위

- 5개 대상 작물의 생육 기온·토양 pH 규칙
- 공식 문서에 수치가 있는 생육 단계별 단기 위험 규칙
- 6개 시·군의 행정구역 코드와 기상청 기후평년 관측소
- 흙톡 재배 참고 코퍼스(`reviewed-knowledge-base.js`)와 이미지 레지스트리
- 농경지화학성 통계정보 V2의 공식 pH 구간별 면적 계약
- Kakao가 반환한 10자리 법정동 코드를 토양 통계 조회키로 재사용

## 의도적으로 HOLD인 범위

- 시설 외기예보는 시설 내부 상태를 확정하지 않고 센서 확인 신호로만 사용
- 배의 생육 적온 `약 20℃`는 범위 점수가 아닌 `SINGLE_TARGET`으로 표시
- 실제 필지 pH·EC는 지역 통계로 추정하지 않고 토양검정 전까지 결측
- 중기예보 세부 구역은 공급자 계약 검증 전까지 미매핑
- 최근 관측소와 거리는 필지 좌표별 계산이 필요하므로 정적 지역표에 저장하지 않음
- 공식 문서에 수치 임계값이 없는 예보 위험은 생성하지 않음
- 재배 참고 문단은 전부 `reviewState: "DRAFT"`이며 농업기술센터·지도사 검수
  전까지 운영에서 노출되지 않음
- 참고 이미지 URL은 NCPMS 도감·농사로의 공개 주소를 사람이 확인하기 전까지
  비워 두며, 응답 구조를 추측해 채우지 않음

## 실행

절대 경로를 `TRUSTED_BACKEND_RUNTIME_MODULE`에 지정한다.

```sh
TRUSTED_BACKEND_RUNTIME_MODULE="/absolute/path/backend-v3/runtime/reviewed-runtime.mjs" npm start
```

API 어댑터가 비활성인 경우에도 규칙과 매핑은 로드되지만 실제 분석 자료는
가짜 값으로 채우지 않고 `HOLD` 또는 `UNAVAILABLE`로 유지된다.
