# 흙톡 관찰 지점 도해

## 이 폴더의 성격

여기 있는 SVG는 **관찰 지점과 방법을 설명하는 도해**다. 실제 증상 사진이
아니고, 사진을 대신하려고 만든 것도 아니다.

증상을 사실적으로 그리지 않는 이유는 안전 때문이다. 사용자가 자기 밭의 작물을
우리가 그린 그림과 맞춰 보고 병을 스스로 확정하면, 흙톡이 하지 않겠다고 정한
진단을 그림이 대신 해 버린다. 그래서 도해는 "어디를, 언제, 어떤 순서로
보라"까지만 담고, 판단은 사용자와 농업기술센터에 남긴다.

모든 도해 오른쪽 아래에 `관찰 지점 도해`라는 라벨을 넣어 사진이 아님을 밝힌다.

## 작성 규칙

- 뷰박스는 `0 0 400 220`으로 고정한다. 화면에서 `object-fit: contain`으로
  표시되므로 비율이 다르면 여백이 생긴다.
- 배경을 칠하지 않는다. 카드 배경이 비쳐야 라이트 테마와 어울린다.
- 스크립트, 외부 참조, 폰트 파일, 래스터 이미지를 넣지 않는다.
  `verify-knowledge-images.js`가 `<script`, `<foreignObject`, `xlink:href`,
  `data:`를 거부한다.
- 텍스트는 `font-family="system-ui, -apple-system, sans-serif"`로 두고
  11~13px을 쓴다. 시스템 폰트만 쓰므로 한글이 기기 폰트로 렌더링된다.
- `<title>`에 도해의 요지를 한 문장으로 적는다. 화면 낭독기는 `<img alt>`을
  읽지만, 파일만 열어 본 사람에게도 의도가 남는다.

## 추가·수정 절차

1. 이 폴더에 `kebab-case.svg`로 파일을 만든다.
2. `../reviewed-knowledge-base.js`의 `KNOWLEDGE_IMAGES`에 `asset`,
   `alt`, `caption`을 등록한다. `credit`과 `licence`는 자체 제작 값을 쓴다.
3. 문단의 `imageId`가 그 항목을 가리키게 한다.
4. `npm run verify:knowledge-images`로 형식과 크기를 검증한다.
