- 기준 브랜치: `KIMI/v2`

## 2. 1년 예보 백테스트 결과

기간은 2025-08-04~2026-08-03, 대상은 8개 검수 지역이다.

| 선행기간 | 최저기온 MAE | 최고기온 MAE | 강수 검증 |
| --- | ---: | ---: | --- |
| D+1 | 1.2828°C | 1.1605°C | 2,352/2,920쌍(80.55%), Brier score 0.1213 |
| D+3 | 1.4386°C | 1.4172°C | 2,344/2,920쌍(80.27%), Brier score 0.1330 |
| D+5 | 1.7840°C | 1.9354°C | 2,920쌍, Brier score 0.1450 |

원본 결과는 [`backtest_1y/extended-forecast-backtest-2025-08-04-2026-08-03.json`](./backtest_1y/extended-forecast-backtest-2025-08-04-2026-08-03.json)에 보존한다. 결측값을 0이나 평균으로 채우지 않았고 현재 예보를 과거 예보로 대체하지 않았다.

D+1·D+3 강수확률은 실행 시점의 공급자 과거자료 보존 범위와 최근자료 공개 지연 사이에서 실제로 조회 가능한 최대 구간까지 수집했다. 전체 기대치 5,840행 중 4,696행이므로 상태는 `PARTIAL`이며, 365일 완료로 표현하지 않는다. 추출기는 기간 중복 재사용과 재개 실행을 지원하므로 이후 날짜를 누적해 연속 365일을 완성한다.

## 3. 공간 대표성과 보정 상태

- 중기예보는 지역 예보이고 검증 정답은 ASOS 지점 관측이다. 이를 필지 미기후 정확도로 표현하지 않는다.
- 평창군 검증 지점인 대관령 ASOS의 공식 고도는 772.43m다.
- 과거 90일 오차만 사용하는 통계 보정 후보에서 미래 관측 사용은 0건이다.
- 평창 최저/최고기온과 부여 최저기온만 배포 후보 기준을 통과했다.
- 후보값은 원 예보를 변경하지 않으며 현재 점수·행동 생성에도 아직 적용하지 않는다.
- 농장 고도 또는 현장 센서가 없으므로 물리적 고도 보정은 적용하지 않는다.
- 운영 후보 프로필은 지역·선행기간·기온항목별로 분리하고 버전, 학습기간, 표본 수, 생성시각, 최대 120일 만료시각을 기록한다.
- 기본값은 원 예보이며 명시적으로 활성화된 프로필만 후보값을 제공한다. 최근 30개 비교쌍에서 MAE·RMSE·절대편향 중 하나라도 악화되면 즉시 원 예보로 롤백한다.

## 4. 아직 완료로 판정하지 않는 범위

1. 공급자 과거자료 보존 범위 때문에 한 번에 확보하지 못한 D+1·D+3 강수확률을 매일 누적해 연속 365일 완성
2. 버전·만료·롤백·드리프트 감시 계약이 구현된 검증 후보 보정의 실제 운영 활성화 승인
3. 농장 좌표의 고도 확보와 별도 검증된 물리적 고도 보정
4. 실제 파종·정식일, 생육단계, 첫·마지막 수확일을 이용한 수확 정확도 검증
5. 실제 피해 발생일을 이용한 작물 피해 경고 정밀도·재현율 검증
6. 과거 필지 토양검정 스냅샷을 이용한 토양 전향 검증
7. 위성 NDVI 결과를 핵심 생육점수에 넣는 검증. 현재는 독립 관찰 근거이며 점수에 가중하지 않는다.
8. 앱이 종료된 상태에서도 동작하는 서버 Web Push와 중복 제거 스케줄러
9. 실제 초보·고령 사용자 대상의 현장 사용성 평가

## 5. 발표·시연 표현 기준

- `기상 예보 정확도 백테스트 완료`는 D+1·D+3 기온과 D+5 기온·강수 범위에서만 사용한다.
- `작물 피해 예측 정확도 검증 완료`, `수확일 정확도 검증 완료`, `필지 기온 확정`이라고 표현하지 않는다.
- 위성·SmartFarm·지역 통계는 독립 참고 근거이며 핵심 생육점수를 높이는 가중치로 사용하지 않는다.
- 위성 기능은 필지 경계를 먼저 저장한 뒤 같은 필지의 시계열 변화만 보여준다. 위성 연결이 꺼져 있어도 필지 경계 저장은 유지된다.
- 지역 통계와 ASOS 지점값을 실제 농장 센서값으로 표현하지 않는다.
