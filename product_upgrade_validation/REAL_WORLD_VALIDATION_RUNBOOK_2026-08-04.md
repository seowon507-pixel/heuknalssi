# 흙날씨 실사용 검증 운영서

- 기준일: 2026-08-04
- 목적: 실제 농장 결과가 없는 상태에서 정확도를 만들어내지 않고, 수집→저장→백테스트→배포 판정을 동일한 계약으로 수행한다.

## 1. 현재 준비된 것

- 수확 결과: 작기별 첫 수확일·마지막 수확일과, 결과를 알기 전에 저장한 예상 범위를 비교한다.
- 피해 결과: 현장·사진으로 확정한 피해 발생일과 사전 경고 유효기간을 비교한다.
- 토양 결과: 분석일 이전에 검정된 최신 필지 스냅샷만 선택하고 3년을 넘긴 값은 점수에서 제외한다.
- 업로드 사진·작기·작업 기록은 농장·작물 범위로 분리한다.
- 결측치를 0이나 평균으로 채우지 않고, 피해 기록이 없는 날을 정상으로 간주하지 않는다.

입력 계약은 [`backtest_1y/input_templates/README.md`](./backtest_1y/input_templates/README.md)를 따른다.

## 2. 실증 순서

1. 농장·작물·작기에 불투명 ID를 발급한다. 원문 주소·PNU·사용자 이름은 분석 CSV에 넣지 않는다.
2. 예상 수확 범위와 위험 경고를 결과를 알기 전에 저장한다.
3. 첫·마지막 수확일, 확정 피해일, 완료 작업, 확인 사진을 작기 종료 전까지 수집한다.
4. 정확한 검정일이 있는 토양 기록만 스냅샷에 넣는다.
5. `cd backend-v3 && npm run verify:backtest:evidence`를 실행한다.
6. 작물별 수확 범위 MAE, 피해 재현율·알림 정밀도, 토양 시점 커버리지를 분리해 판정한다.

## 3. 배포 게이트

| 영역 | 활성화 조건 | 실패 시 동작 |
| --- | --- | --- |
| 기온 통계 보정 | 독립 비교 180쌍 이상, MAE·RMSE 각 0.1°C 이상 개선, 편향 감소, 유효기간 내 | 원 예보 사용 |
| 보정 드리프 | 최근 검증 30쌍에서 원 예보보다 MAE·RMSE·절대편향 개선 | 즉시 `ROLLBACK_TO_RAW` |
| 수확 예상 | 실제 작기 코호트에서 작물별 범위 MAE 7일 이하 목표 | ‘일정 예상’으로만 표시 |
| 피해 경고 | 확정 피해 레코드와 사전 알림이 충분한 작물별 표본 | 정확도 주장 보류 |
| 토양 | 분석 시점 이전 필지 검정 이력 | 지역 통계를 필지 실측값으로 표현하지 않음 |

## 4. 위성·챗봇·알림 운영 경계

- 위성 NDVI는 필지 경계를 저장한 뒤 독립 관찰 기능으로 제공한다. 원인 진단이나 생육점수 가중치로 사용하지 않는다.
- 챗봇은 현재 분석·작기·검수 지식 범위에서만 답하며, 농약 용량·사진 확정 진단은 차단한다. 대화 기억은 개인정보 보존 정책과 삭제 계약이 없으므로 활성화하지 않는다.
- 현재 알림은 서비스워커를 이용한 기기 알림이다. 앱이 종료된 후에도 서버가 보내는 Web Push를 출시하려면 VAPID 키, HTTPS 배포 주소, 구독 저장 정책, 스케줄러, 수신 해제·삭제 흐름이 추가로 필요하다.

## 5. 현재 실행 결과

`verify:backtest:evidence`는 정답 레코드가 없는 현재 상태를 `COLLECTION_PIPELINE_READY`로 반환했다. 수확·피해 정확도는 `null`이며, 미라벨 날을 정상으로 간주하거나 현재 토양을 과거 토양으로 대체한 건수는 0건이다.

- 챗봇·행동·백테스트·리포트 회귀 테스트: 58/58 통과
- UI 행동·챗봇 일정 응답 테스트: 29/29 통과
- 실측 입력 현황: 작기 결과 0건, 확정 피해 0건, 과거 토양 스냅샷 0건
- 따라서 수확·피해·토양 정확도는 아직 `null`이며, 샘플이나 추정값으로 채우지 않는다.
