## 완성된 제품 흐름

- 재배 준비와 재배 중 흐름을 분리하고 5개 작물(사과·배·오이·감자·상추)을 지원한다.
- 농장·작물·시즌별 재배 진행률, 수확 준비 기간, 예상 수확 기간과 새 시즌 시작을 제공한다.
- 다중 농장·다중 작물의 분석, 할 일, 토양검정, 사진과 시즌 상태를 서로 격리한다.
- 상세 주소가 있으면 필지 토양검정·토양특성을 사용하고, 시·군·구만 있으면 지역 참고 분석임을 한 번 명시한다.
- 생육점수와 일정 진행률을 분리하고 날씨·토양·예보의 원인, 위험, 필요한 행동과 재확인 시점을 연결한다.
- 챗봇은 현재 농장의 분석과 재배일정을 근거로 답하고, 만료 분석은 한 번만 복구한다.
- 병해충 화면은 기상 위험과 병해 진단을 분리하고 5개 작물의 검수된 NCPMS 현장 관찰 가이드를 제공한다.
- 사진 기록, 농장 설정 이관, 큰 글자·고대비·알림, 무료 토양검정 안내를 제공한다.

## 감사 중 발견하고 해결한 결함

1. 모바일 새 분석 버튼이 42×40px이던 문제를 44×44px로 수정하고 회귀 검사를 추가했다.
2. 만료된 병해충 분석이 내부 요청 ID를 노출하던 문제를 해결했다.
   - 저장 조건으로 최신 분석을 한 번 복구한다.
   - 실패하면 검수된 작물별 관찰 가이드로 전환한다.
   - 내부 분석 ID·기술 오류 문자열은 사용자 화면에 표시하지 않는다.
3. 다중 작물에서 두 번째 작물의 만료 분석을 복구할 때 첫 작물로 바뀌던 문제를 해결했다.
   - 복구 전 작물 코드를 보존한다.
   - 새 분석에서도 같은 작물만 다시 선택한다.
   - 해당 작물이 실패하면 기존 작물 컨텍스트와 검수 가이드를 유지한다.
