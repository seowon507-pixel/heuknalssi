# 흙날씨 Diary Sticker Icon System

흙날씨의 작물·환경 아이콘은 농장 다이어리의 페이지에 붙이는 작은 종이 스티커를 모티브로 합니다. 할 일과 관찰 기록을 정서적으로 연결하되, 농업 정보를 빠르게 알아보는 제품 아이콘의 역할을 우선합니다.

## 시각 원칙

- `24×24` 좌표계와 `1.2~1.4px`의 부드러운 웜 그레이 잉크선을 사용합니다.
- 흰색 외곽선을 한 겹 두어 종이에 붙인 다이컷 스티커처럼 보이게 합니다.
- 작물 고유 실루엣과 환경 신호를 먼저 읽을 수 있게 하고, 표정이나 캐릭터 얼굴은 넣지 않습니다.
- 색은 흰색 테두리·잉크선·주요색·보조색을 포함해 아이콘당 최대 4색으로 제한합니다.
- 하이라이트는 한 곳만 사용하며, 질감·필터·그라디언트·3D 플라스틱 광택은 사용하지 않습니다.
- 귀여움은 둥근 형태와 차분한 저채도 팔레트에서 만들고 유아용 이모지처럼 과장하지 않습니다.

## 권장 크기

| 크기 | 용도 |
| --- | --- |
| 20px | 작물 전환 탭, 조밀한 다이어리 메타 정보 |
| 24px | 할 일 카드, 관찰 기록, 예보 항목 |
| 28px | 대시보드 환경 상태 축 |
| 32px | 온보딩 작물 선택, 다이어리 표지 작물 |

16px 이하에서는 종이 테두리가 뭉칠 수 있으므로 제품 기본 크기로 사용하지 않습니다.

## 접근성

- 아이콘은 보조 시각 요소이며 정보의 유일한 전달 수단으로 사용하지 않습니다.
- 작물명·상태·할 일 텍스트를 항상 함께 표시합니다.
- SVG는 `aria-hidden="true"`와 `focusable="false"`를 유지합니다.
- 선택·완료·주의 상태는 `aria-pressed`, checkbox, 텍스트와 색을 함께 사용합니다.

## 사용 금지

- 운영체제 이모지나 서로 다른 화풍의 스톡 아이콘을 섞지 않습니다.
- 얼굴, 과한 반짝이, 입체 플라스틱 그림자, 장면형 미니어처를 추가하지 않습니다.
- 다색 SVG를 단색 마스크로 바꿔 작물의 식별색을 제거하지 않습니다.
- 아이콘을 비율과 다르게 늘리거나 20px 미만으로 축소하지 않습니다.
